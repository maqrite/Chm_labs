Требования к выполнению и сдаче лабораторных работ.

Общие требования:

1. Все лабораторные работы сдаются в виде программного кода. Использовать можно любой язык программирования.

2. На сдаче я буду задавать вопросы как по теории, так и по вашему коду.

— Если вы не ответили на вопрос по теории, можно пойти подучить материал и попробовать ответить ещё раз.  
— Если вы не можете объяснить свой код, повторная сдача будет уже в другой день. В этот же день продолжить сдачу не получится.

3. Входные данные не должны вводиться через консоль или быть захардкожены в коде. Можно сделать небольшое приложение с формой для ввода данных или реализовать чтение данных из файла.

4. Программа должна быть универсальной. Размерность матрицы не должна быть жёстко задана в коде: при вводе матрицы большей размерности программа должна продолжать корректно работать, если входные данные соответствуют условиям применимости метода.

5. Сдача лабораторных работ проходит только очно.

6. Если группе нужно дополнительно разобрать какую-либо тему, я могу сделать это во время лабораторной работы. Для этого напишите мне в личные сообщения за 1–2 дня до занятия и укажите, какой именно материал нужно объяснить.

7. Использовать готовые реализации численных методов нельзя. Например, NumPy можно применять только для проверки и сравнения результатов собственной реализации, если в требованиях к конкретному заданию не указано иное.

Требования к лабораторной работе № 1

1.1. LU-разложение

Обязательно реализовать выбор опорного элемента.

В результате работы программы необходимо вывести:

1. Матрицы L и U.
2. Результат умножения L · U.
3. Решение системы Ax = b.
4. Обратную матрицу A⁻¹, найденную через LU-разложение.
5. Определитель матрицы A, найденный через LU-разложение.
6. Проверку A · A⁻¹ = E.
7. Проверку L · U = P · A, где P — матрица перестановок.

1.2. Метод прогонки

При реализации ЗАПРЕЩЕНО хранить всю матрицу (т.к. она является разреженной). Хранить нужно только значения, лежащие на главной диагонали и двух побочных)

Необходимо вывести:

1. Все прогоночные коэффициенты.
2. Итоговое решение системы уравнений.

1.3. Метод простых итераций и метод Зейделя

Необходимо реализовать оба метода и вывести:

1. Заданную точность вычислений ε.
2. Количество итераций для каждого метода.
3. Точное или эталонное решение для проверки результата.
4. Сравнение методов по скорости сходимости.

1.4. Метод вращений Якоби

Необходимо предусмотреть и вывести:

1. Заданную точность вычислений ε.
2. Найденные собственные значения.
3. Найденные собственные векторы и матрицу собственных векторов.
4. Проверку A · V = V · Λ, где V — матрица собственных векторов, а Λ — диагональная матрица собственных значений.

1.5. QR-разложение

Необходимо вывести:

1. Исходную матрицу A.
2. Матрицы Q и R.
3. Результат умножения Q · R.
4. Найденные собственные значения.

Также необходимо привести собственный пример матрицы с комплексно-сопряжёнными собственными значениями.

Только в этой части допускается использование NumPy для нахождения и проверки комплексно-сопряжённой пары[1084;1:3u собственных значений.
