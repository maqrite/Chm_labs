# Лабораторная работа № 2 — Вариант 7

Решение нелинейных уравнений и систем нелинейных уравнений методом простой
итерации и методом Ньютона.

| Задание | Условие |
|---|---|
| **2.1** | `2^x + x² − 2 = 0` — найти положительный корень |
| **2.2** | `x₁² + x₂² − a² = 0`, `x₁ − e^{x₂} + a = 0`, `a = 2` — найти решение с положительными неизвестными |

## Запуск

```bash
python3 main.py                 # оба задания, данные из input/, отчёт в out/
python3 main.py --task 1        # только задание 2.1
python3 main.py --task 2        # только задание 2.2
python3 main.py --eps 1e-12     # переопределить точность
python3 main.py --task 2 --input-2 input/example_3d.json     # проверка универсальности (n = 3)
```

Зависимости: стандартная библиотека и `matplotlib` — все графики строятся
им и сохраняются в png-файлы каталога `out/`.
`numpy` используется **только** для контрольной проверки невязки найденного
решения — ни один численный метод через него не реализован.

Результат: отчёт `out/report.txt` и графики `out/*.png`.

## Входные данные

Ничего не зашито в коде и ничего не вводится с консоли — всё читается из
json-файлов. Уравнения, производные, итерационные функции задаются **строками**
и компилируются в функции (`src/expr.py`), поэтому файл можно поменять целиком,
не трогая код.

`input/task_2_1.json`:

| поле | смысл |
|---|---|
| `f`, `df` | левая часть уравнения и её производная (если `df` убрать — берётся разностная производная) |
| `epsilon`, `max_iterations` | точность и лимит итераций |
| `search_interval`, `search_steps` | где и с каким шагом отделять корни |
| `graphic` | представление `y₁(x) = y₂(x)` для графического отделения корня |
| `phi_variants` | варианты `φ(x)` для метода простой итерации: выражение, отрезок, комментарий |
| `epsilon_series` | набор ε для анализа «число итераций ↔ точность» |

`input/task_2_2.json`:

| поле | смысл |
|---|---|
| `variables`, `constants` | имена неизвестных и параметры (здесь `a = 2`) |
| `F` | список левых частей уравнений (длина = размерность системы) |
| `J` | матрица Якоби в виде выражений (если убрать — считается численно) |

**Размерность нигде не фиксирована**: она берётся как длина списка `F`.
СЛАУ на шаге Ньютона решается собственным методом Гаусса для произвольного n.
Файл `input/example_3d.json` — рабочий пример на системе из трёх уравнений
(решение `x = (1, 2, 3)`).

## Что делает программа

### Задание 2.1

1. **Графическое отделение корня.** Уравнение приводится к виду `2^x = 2 − x²`;
   строится график (png). Затем отрезок перебирается с шагом, и
   отбираются отрезки перемены знака `f(x)` — это численный аналог того, что
   делает глаз по картинке. Их два: `[−1.26, −1.25]` и `[0.65, 0.66]`; берётся
   положительный.
2. **Эталонный корень** — метод половинного деления до `1e−15`:
   `x* = 0.653482524784174`.
3. **Метод простой итерации.** Для каждого варианта `φ(x)` проверяются оба
   достаточных условия сходимости (`φ([a,b]) ⊂ [a,b]` и `q = max|φ′(x)| < 1`),
   печатается вся таблица итераций.
4. **Метод Ньютона.** Начальное приближение выбирается из условия
   `f(x₀)·f″(x₀) > 0` — тогда сходимость монотонная и гарантированная.
5. **Сравнение**: таблица погрешности по итерациям, эмпирический порядок
   сходимости, график в логарифмическом масштабе, таблица «ε ↔ число итераций».

### Задание 2.2

1. **Графическое отделение решения** — кривые `f₁ = 0` (окружность радиуса `a`)
   и `f₂ = 0` на плоскости `(x₁, x₂)`; видно два пересечения.
2. **Поиск всех решений**: метод Ньютона запускается из узлов сетки, найденные
   решения группируются. Их два, положительное — одно.
3. **Эталонное решение** — метод Ньютона с точностью `1e−14` + контроль невязки
   средствами NumPy.
4. **Метод простой итерации** с проверкой `Φ(G) ⊂ G` и `q = max‖Φ′(x)‖∞ < 1`.
5. **Метод Ньютона**: на каждом шаге решается `J(xᵏ)·Δx = −F(xᵏ)` методом Гаусса
   с выбором главного элемента, затем `xᵏ⁺¹ = xᵏ + Δx`.
6. **Сравнение** — как в 2.1.

### 2.2  `x₁² + x₂² = 4`, `x₁ + 2 = e^{x₂}`

| Простая итерация (q = 0.915) | 28 | 0.480 | 0.99 |

### Зависимость погрешности от числа итераций

Метод простой итерации сходится **линейно**: погрешность убывает как
геометрическая прогрессия, `eₖ ≈ C·qᵏ`, поэтому на логарифмическом графике это
прямая, а число итераций растёт как `ln(1/ε)`. Видно и по таблице «ε ↔ итерации»:
на каждый порядок точности требуется примерно одинаковая добавка итераций
(≈ 13 для `φ = √(2 − 2^x)`, ≈ 3–4 для системы).

Метод Ньютона сходится **квадратично**: `e_{k+1} ≈ C·eₖ²`, число верных знаков
удваивается за итерацию, поэтому при переходе от ε = 1e−2 к ε = 1e−11 число
итераций растёт всего с 1 до 4. Ускорение достигается ценой вычисления
производной (в системе — всей матрицы Якоби и решения СЛАУ на каждом шаге).

## Теория (к защите)

**Метод простой итерации.** Уравнение `f(x) = 0` приводится к виду `x = φ(x)`,
итерации `x_{k+1} = φ(x_k)`. Теорема о сжимающем отображении: если на отрезке
`[a, b]` выполнено `φ([a,b]) ⊂ [a,b]` и `|φ′(x)| ≤ q < 1`, то итерации сходятся
к единственному на `[a, b]` корню при любом `x₀ ∈ [a, b]`, причём

```
|x_k − x*| ≤ q/(1 − q) · |x_k − x_{k−1}|        (апостериорная оценка)
|x_k − x*| ≤ qᵏ/(1 − q) · |x₁ − x₀|              (априорная оценка)
```

Апостериорная оценка и взята критерием остановки — при `q`, близких к 1,
обычная проверка `|x_k − x_{k−1}| ≤ ε` даёт слишком оптимистичный результат.
Третий вариант `φ` в `input/task_2_1.json` добавлен специально: там `q ≈ 1.34`,
условие нарушено и процесс расходится, хотя корень тот же самый — выбор `φ`
определяет сходимость.

Универсальный способ получить сходящуюся `φ` — релаксация:
`φ(x) = x − f(x)/M`, где `M ≥ max|f′(x)|` того же знака, что `f′`; тогда
`φ′(x) = 1 − f′(x)/M ∈ [0, 1)`.

**Метод Ньютона** — линеаризация: `f(x_{k+1}) ≈ f(x_k) + f′(x_k)(x_{k+1} − x_k) = 0`,
откуда `x_{k+1} = x_k − f(x_k)/f′(x_k)`. Геометрически — пересечение касательной
в точке `x_k` с осью Ox. Это частный случай простой итерации с
`φ(x) = x − f(x)/f′(x)`, у которой `φ′(x*) = 0`, поэтому сходимость
квадратичная: `|x_{k+1} − x*| ≤ M₂/(2m₁) · |x_k − x*|²`, где
`M₂ = max|f″|`, `m₁ = min|f′|`. Сходимость гарантирована, если на `[a, b]`
производные `f′` и `f″` не меняют знак и `f(x₀)·f″(x₀) > 0`.

**Системы.** Простая итерация: `x = Φ(x)`, условие сжатия —
`q = max_G ‖Φ′(x)‖ < 1`, где `Φ′` — матрица Якоби отображения `Φ`, норма
согласована с нормой вектора (в программе — `‖·‖∞`, максимум суммы модулей по
строке). Метод Ньютона: `F(x) ≈ F(xᵏ) + J(xᵏ)(x − xᵏ) = 0`, то есть на каждом
шаге решается линейная система `J(xᵏ)·Δx = −F(xᵏ)` и `xᵏ⁺¹ = xᵏ + Δx`.
Якобиан должен быть невырожден в окрестности решения.

**Почему метод Гаусса с выбором главного элемента.** Без выбора ведущего
элемента деление на малый по модулю элемент резко увеличивает вычислительную
погрешность; перестановка строк ставит на диагональ максимальный по модулю
элемент столбца и делает исключение устойчивым.
